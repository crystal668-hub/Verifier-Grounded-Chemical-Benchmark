# RealChem 题目审核系统快速使用手册

本手册面向第一次使用 RealChem 题目审核系统的协作者，介绍从访问网站、注册账号到审阅题目和参与讨论的完整流程。

## 1. 访问前准备

建议使用最新版 Chrome、Edge、Safari 或 Firefox 浏览器。

系统采用两层登录保护：

1. 访问入口认证：用于进入审核网站，请向邀请你参与审核的联系人获取入口密码。
2. 个人账号认证：每位用户自行注册独立账号，用于保存个人身份和协作记录。

请勿与他人共享个人账号密码，也不要将入口密码发布在公开渠道。

## 2. 打开审核系统

访问以下地址：

<https://sealtun-realchem-review-panel-ns-humdhs5d.sealosgzg.site>

浏览器首先会显示一个系统认证窗口。请输入：

- 用户名：`vgb-review`
- 密码：向邀请联系人获取的访问入口密码

认证成功后，浏览器会打开“题目审核工作台”的登录页面。

如果浏览器反复显示认证窗口，通常表示入口用户名或密码不正确。请重新输入，或向邀请联系人确认当前入口密码。

## 3. 注册个人账号

首次使用时，在登录页面完成以下操作：

1. 点击“注册”页签。
2. 输入准备使用的用户名。用户名必须唯一，建议使用便于其他协作者识别的名称。
3. 输入至少 6 位密码。
4. 在“再次输入密码”中重复输入相同密码。
5. 点击“注册并进入工作台”。

注册成功后会自动进入审核工作台，无需再次登录。

可能遇到的提示：

- “用户名已存在”：该名称已被使用，请更换用户名。
- “两次输入的密码不一致”：请重新确认两次密码输入。
- “注册失败”：检查网络后重试；持续失败时联系邀请人。

每位协作者应注册自己的账号，不要多人共用同一个个人账号。

## 4. 再次登录

以后访问系统时：

1. 完成浏览器弹出的访问入口认证。
2. 在工作台登录页面选择“登录”。
3. 输入个人用户名和密码。
4. 点击“进入工作台”。

连续多次输入错误密码会触发临时保护。遇到“登录尝试过多”时，请等待一段时间后再试。

## 5. 认识题目审核界面

登录后默认进入“题目审核”模块。界面由目录、题目主面板和附件栏三部分组成。

### 5.1 左侧目录

左侧按 track 展示题目集合。当前可浏览：

- RDKit 小分子任务
- xTB 分子优化任务
- 基础性质计算任务
- 高级性质计算任务

点击 track 名称可以展开或折叠题目列表，点击题目 ID 即可打开对应题目。

目录顶部的搜索框可按题目 ID 或题目内容搜索。清空搜索内容即可恢复完整列表。

### 5.2 中间题目主面板

主面板顶部显示当前 track、题目版本、题目 ID 和审核状态，并提供四个页签：

- “题目内容”：查看完整题意、输入说明和作答要求。
- “评分细则”：查看评分字段、标准答案、满分条件、有效得分区间、单位和评分配置。
- “Schema”：查看任务类型、答案格式、能力标签、输入对象及其他结构化元数据。
- “讨论”：查看其他协作者的批注并发表自己的审核意见。

数值较大或较小时，评分页面可能使用科学计数法显示。多字段题目会分别列出每个字段的评分规则，并显示最终聚合方式。

### 5.3 右侧附件栏

CIF、XYZ 等篇幅较长的输入不会在中间主面板展开。中栏只显示“在右栏查看附件”按钮以及附件名称等信息。

查看附件的方法：

1. 在题目内容中点击“在右栏查看附件”，或直接点击右侧附件列表中的文件。
2. 附件完整内容会在右栏打开。
3. 可以拖动左右分隔线调整目录、主面板和附件栏宽度。
4. 可以点击附件栏折叠按钮收起或重新展开右栏。

若右栏显示“本题没有附件”，表示该题全部必要信息已经包含在题目内容中。

## 6. 推荐的题目审核流程

对每道题建议依次完成以下检查：

1. 在“题目内容”中确认问题描述是否明确，输入条件和输出格式是否一致。
2. 打开右栏附件，确认结构数据完整、可读，并与题目描述对应。
3. 在“评分细则”中核对标准答案、单位、满分条件和有效得分范围。
4. 在“Schema”中核对题目类型、答案格式和输入对象。
5. 在“讨论”中记录发现的问题、疑问或审核结论。
6. 从左侧选择下一道题继续审核。

如果只是需要重新获取最新内容，可点击页面右上角的刷新按钮。

## 7. 发表与删除审核批注

进入题目的“讨论”页签后：

1. 在底部输入框中填写审核意见。
2. 点击发送按钮，或按 Enter 键发布。
3. 发布成功后，批注会显示用户名和正文。

你可以删除自己发布的批注：

1. 点击批注右侧的删除图标。
2. 点击“确认”完成删除，或点击取消按钮保留批注。

删除后无法通过网页恢复。提交前请确认批注没有遗漏必要信息。

建议在批注中清楚说明问题位置和修改建议，例如：

```text
评分单位与题干要求不一致，题干要求 kcal/mol，评分规则显示为 kJ/mol。
```

## 8. 当前功能说明

“提交 task 草稿”入口目前尚未开放。点击后出现“草稿提交功能即将开放”提示属于正常现象。

题目内容、评分规则、Schema 和附件均来自当前审核题库。发现内容缺失或明显不一致时，请在对应题目的“讨论”页签留下批注。

## 9. 常见问题

### 浏览器一直要求输入用户名和密码

这是访问入口认证。确认用户名为 `vgb-review`，并使用邀请联系人提供的入口密码。

### 页面提示用户名或密码错误

这是个人账号登录失败。确认使用的是注册时创建的个人账号，而不是访问入口用户名。

### 注册后没有进入工作台

检查页面是否显示用户名重复、密码长度不足或两次密码不一致。修正后重新提交。

### 题目列表或内容没有加载

确认网络连接正常，然后点击右上角刷新按钮。若公网入口暂时中断，请稍后重试。

### 附件为什么不在题目正文中展开

这是系统的固定展示规则。附件正文只在右侧附件栏显示，中间主面板只保留附件入口和元信息。

### 忘记个人账号密码

当前网页不提供自助找回密码。请联系邀请你参与审核的联系人处理。

## 10. 使用安全建议

- 不要向他人转发访问入口密码或个人账号密码。
- 不要在批注或共享资料中填写密码、访问令牌或个人敏感信息。
- 在共享电脑上使用后，应清理该网站的浏览器登录数据。
- 遇到异常页面、可疑提示或无法确认的操作时，先停止操作并联系邀请人。
