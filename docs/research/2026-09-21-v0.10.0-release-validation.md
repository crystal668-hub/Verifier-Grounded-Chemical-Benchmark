# v0.10.0 Release Validation

Date: 2026-09-21.

v0.10.0 removes the packaged family policy and its loader/validation dependency.
Each task retains its own scoring profile. Basic 013 now uses a 3 kcal/mol
zero-score width. Advanced 008, 010, and 013 use 10 kcal/mol, 0.1 angstrom,
and 5 kcal/mol respectively, comparing absolute answer and gold values.
Both fields in Advanced 008 and 010 use the new rules. Advanced 011 already
specified a spherical probe radius of 1.2 angstrom; that prompt is preserved
and now covered by a regression test.

RDKit's 14 task IDs are `rdkit_001` through `rdkit_014`; xTB's 20 IDs are
`xtb_001` through `xtb_020`. Pack configuration, sample answers, active scripts,
calibration references, tests, and current documentation use the new IDs.
Existing answer records must update their task IDs using the
[migration table](../design/task-id-v0.10.0-migration.md). Historical releases and
research artifacts retain their original IDs.

resolve. Both signs, midpoint, boundary, and outside-boundary scores for Advanced
008/010/013 passed. Basic 013 retains signed scoring with its new width; Advanced
011 retains the 1.2 angstrom probe condition. The removed policy resource is
absent. This does not claim live execution of every optional chemistry backend.
