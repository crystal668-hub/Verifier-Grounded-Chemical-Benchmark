# v0.10.0 Release Validation

Date: 2026-09-21. Revised release, replacing the earlier local v0.10.0 build and
moving its tag with the benchmark owner's explicit authorization.

## Released behavior

The canonical tracks are `open_generation_rdkit` (14 tasks),
`open_generation_xtb` (20), `property_calculation_basic` (51), and
`property_calculation_advanced` (20). Open-generation task IDs retain their
original descriptions after the three-digit number, such as `rdkit_001_qed_max`
and `xtb_001_gap_window`. See the complete
[migration table](../design/task-id-v0.10.0-migration.md).

Only open-generation tasks use verifier specifications and execute chemistry
backends to measure candidate properties. Property Calculation tasks compare
submitted values against gold answers and independent scoring profiles. Their
empty `verifier_specs.yaml` placeholders are removed. Registration, loading, and
the custom-pack CLI accept property-only packs without verifier resources or
external dependency preflight. Open-generation and mixed packs still require
verifier specifications, and invalid verifier references are rejected.

The earlier approved scoring changes are preserved: Basic 013 uses a 3 kcal/mol
zero-score width; Advanced 008, 010, and 013 use 10 kcal/mol, 0.1 angstrom, and
5 kcal/mol, respectively, comparing absolute answer and gold values. Both fields
in Advanced 008 and 010 follow those rules. Advanced 011 retains its explicit
spherical probe radius of 1.2 angstrom. No family-wide tolerance constraint is
loaded or enforced. Gold values, scoring profiles, weights, and task order are
unchanged by this revision.

All 150 Python files in `src/verifier_grounded_benchmark` were scanned for
maintenance documentation. The revision adds 215 English docstrings across
106 files, including all previously missing module docstrings, public API
contracts, loader invariants, scoring semantics, verifier protocols, and key
backend entry points. An obsolete result-schema-v2 module description now says
v3. AST comparisons with docstrings stripped confirmed that the documentation
pass introduced no executable changes. Runtime changes are limited to track
registration, loading, resource access, and the CLI.

- Full benchmark suite: 634 passed, 15 skipped. Skips require optional live
  backends or private calibration answers. One existing CIF-parser warning remains.
- The final documentation-only refinements passed 164 focused evaluation and
  OpenMM tests. Final loader/CLI checks passed 15 tests.
- `ruff check src scripts tests`, `uv lock --check`, and `git diff --check`: passed.
- `./review_system/scripts/pipeline.sh test`: 31 passed and the frontend production
  build passed. Existing FastAPI lifecycle and Vite configuration warnings remain.

  approved track/task identifiers changed relative to the earlier v0.10.0 source.
- The exact release wheel was installed without dependencies into a fresh
  temporary virtual environment, using existing third-party dependencies. Checks
  ran outside the source checkout: all four tracks loaded; all 71 property gold

  xTB sample IDs resolved; both property custom-pack CLIs ran without `--specs`.
  Sign equivalence and tolerance boundaries for Advanced 008/010/013 passed,
  Basic 013 retained signed scoring, and Advanced 011 retained the probe condition.
- Release attestation checks bind the replacement tag and source tree, descriptive
  ID inventory, profile hashes, selected tolerances, and artifact checksums.
