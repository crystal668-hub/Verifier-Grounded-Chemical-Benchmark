# 候选容差的化学与发布评估

日期：2026-09-17。基点：`e767f13`，候选参数来自
[2026-09-16 投影实验](2026-09-16-property-tolerance-projection.md)。

后续决定：[按性质统一的容差策略](2026-09-17-property-tolerance-policy.md)。出题者已明确
Advanced 008、013 接受两种能量符号约定，保留按绝对值评分并删除题面的保号要求。
因此下文基于旧题干提出的这两题“错误符号”判断属于历史语义冲突，不能继续解释为
两种符号在本题中必有一种化学错误。绝对差、体积比和距离的非负约束另行修复。

本轮只评估和记录，不修改 gold、题干、评分程序或任何 `scoring.yaml`。
覆盖 Basic 51 题、Advanced 20 题，共 77 个字段，其中 71 个数值字段、6 个非数值字段。
依据包括当前题干、配置、历史变更、正式评分器反例测试，以及下文列出的原始数据、
软件手册、论文全文或摘要。没有重新运行量子化学、晶体自由能或孔体积计算；
没有取得并逐一验证所有专家原始输出，因而不把文献数量级判断写成已完成的误差校准。

## 主要结论

**当前候选容差整体不具备直接发布的科学依据，但也不能把每一个数值都判为化学错误。**

| 用户关心的问题 | 本轮结论 |
| --- | --- |
| 化学上真实有效吗？ | 部分参数数量级可理解；但存在给负绝对差、负距离、负孔体积比或错误符号满分/部分分的确定反例，还有题干与 gold 所指对象不一致的风险。 |
| 科学吗？ | 线性评分、按性质选择绝对/相对尺度，以及速率在 log10 空间评分，都可以成立；当前精确宽度由四组答案方差拟合，缺少独立科学校准，尚不能称为已验证的容差。 |
| 适合发布且可解释吗？ | 尚不充分。“这个宽度能让这四组回答分开”能解释实验目的，不能解释为什么同类题应承受不同精度要求。先定义可接受误差及其证据，再使用独立开发集优化区分度。 |

这修正了对前轮结果可能过强的解读：Basic 的部分留出统计改善只支持区分度，
不能替代化学有效性验证。对四组顺序对称的选参目标可以避免直接按模型名字加权，
但仍然会拟合这四组答案的误差结构。

## 首先解释 τ 的含义

这里的 `τ` 是**零分锚点距离**，不是满分区间，也不自动等于实验误差、标准差或 95%
置信半宽。对当前对称的 identity 数值题：

```text
score = 100 × max(0, 1 - |x - gold| / τ)
90 分：|x - gold| ≤ 0.1τ
50 分：|x - gold| ≤ 0.5τ
0 分：|x - gold| ≥ τ
```

例如 Basic 激发能的 `τ=0.5 eV`，达到 90 分要求误差不超过 **0.05 eV**。
Advanced O–H 距离的 `τ=0.3 Å`，90 分要求误差不超过 **0.03 Å**。
只看零分边界便称它们“太宽”，或者把文献 RMSE 直接设为 τ，都会误读规则。

独立不确定度约束的是评分精度下限；τ 还表达 benchmark 对误差的效用选择。
若经独立验证的可接受误差为 `u`，希望这个误差至少得 `s*`（0–1），应有：

```text
τ ≥ u / (1 - s*)
```

例如要求误差 u 得到至少 90 分，就需 τ≥10u。把 τ直接设成 u，会让达到 u 的合理
复现答案得零分。本式只是保留线性规则时的评分锚点映射，不要求统一采用 90 分；
选用何种锚点应预先说明。RMSE、MAE、数值重复性、实验误差和置信区间也不能互换。

## 必须先处理的发现

### 1. 极宽的晶相势能容差不能由全零作答证明合理

Advanced 002 的 gold 为 `0.079 eV`，τ由 `1` 放宽到 **7.88 eV**，约为 gold 的
100 倍。提交 **0 eV 得 99.00 分**（数值字段），`−0.1 eV` 得 **97.73 分**。
这道题问的是绝对差，负值不符合目标定义；而对 0.079 eV 的差值要求，几乎不分辨
“没有能量差”的 99 分也很难解释。若两个相名正确，总分仍是三个字段算术平均；
数值字段占三分之一，不能说它完全不影响总分。

必须先说明能量按晶胞、化学式单元还是分子归一化，以及电子结构方法、几何/晶胞是否
优化。7.88 eV 的物理尺度取决于这个归一化，因此本轮不擅自把它换算成“每摩尔分子”
能量。负值可得分原已存在；本轮放宽进一步弱化了分辨能力。

### 2. 孔体积比的放宽掩盖了定义问题，并新增非物理得分

Advanced 011 新支撑范围是 `(-0.357, 3.783)`。提交比值 **−0.1 得 12.42 分**，
原规则得零分，这是本轮放宽新增的风险。提交 0 得 17.25 分；0 本身是可能的孔体积比，
但负比值不是。

Zeo++ 文档中 NAV 是**不可达的孔穴体积**，不必等于 `晶胞总体积−AV`；它还区分
probe-accessible volume 与 probe-occupiable volume。题面只写 accessible/inaccessible，
维护记录给出 `114.008/66.5548`，但没有在公开题面中固定对应输出定义。[R8]
因此四组同向偏离可能来自分母/孔体积定义、原子半径或可达性算法，不能直接视为
“计算噪声大，故 τ应放宽”。需要检查原始 Zeo++ 命令、AV/NAV 字段、探针/通道半径、
周期边界、采样点数及随机误差。

### 3. 原有 absolute 变换有真实的符号/物理域问题

正式评分器核验如下。分数是字段分，不是多字段任务总分：

| 反例 | 旧规则 | 候选规则 | 来源 |
| --- | ---: | ---: | --- |
| Advanced 001 绝对自由能差填 −0.1 kJ/mol | 96.42 | 85.96 | 已有域约束缺失，缩窄只减轻 |
| Advanced 002 绝对势能差填 −0.1 eV | 82.10 | 97.73 | 已有缺失，被放宽加重 |
| Advanced 008 相互作用能填 +69.04 kcal/mol，gold 为 −69.04 | 100 | 100 | 已有 absolute 变换，容差无法修复 |
| Advanced 010 O–H 距离填 −1.029 Å | 100 | 100 | 已有 absolute 变换，容差无法修复 |
| Advanced 011 孔体积比填 −0.1 | 0 | 12.42 | 本轮放宽新增 |
| Advanced 013 卤键能填 +17.11 kcal/mol，gold 为 −17.11 | 100 | 100 | 已有 absolute 变换，容差无法修复 |

能量题 008、013 明确要求保留符号；距离不能为负。这些不是所有候选容差都“造成”
的问题，但它们会妨碍将当前评分体系连同新容差一起发布。对 identity 非负量，可先
限制左宽度不超过 gold，保持线性规则；对 absolute 变换下的正负同分，仅调宽度不能
纠正，需要另立语义修复。本轮只记录。

Basic 015 的 τ=2.109 kcal/mol 大于结合能 gold 的绝对值 1.33：不结合（0）得 36.94
分，+0.5 得 13.23 分。正结合能不是普遍非法输入，但它与这个稳定复合物的有利结合
结论相反；是否应仍有部分分，需要明确的化学效用锚点，不能仅用整体均分辩护。

### 4. Basic 031 的目标原子发生过语义变化

`740f58b` 将题干从 `zero-based atom index 1` 改成 `radical-center carbon atom`，
gold 仍是 −0.266。对 `[CH2]C=C`：

| 零基索引 | 化学位置 | SMILES 标记的未成对电子数 |
| --- | --- | ---: |
| 0 | 端位 [CH2] | 1 |
| 1 | 中间碳 | 0 |
| 2 | 另一端位碳 | 0 |

原子连接和 SMILES 自由基标记已用 RDKit 核验。真实自旋在共振体系中离域，
SMILES 的局域自由基标记不等于完整量子自旋密度；但“中间碳”与“自由基中心”并非
无歧义的同一原子。**确定的是题面指代改变；未经原始输出复核，不宣称 −0.266 一定
算错。**先统一原子映射，再讨论 τ=0.1064，否则四组相近也可能共同沿用了旧目标。

### 5. 合理文献答案可能因 gold 中心不同而被明显扣分

FreeSolv v0.52 实验列与当前 gold 并不相同。[R1,R2]

| Basic | 当前 gold | FreeSolv 实验值 | 数据中的 uncertainty | 实验中心值按候选规则所得分 |
| --- | ---: | ---: | ---: | ---: |
| 001 甲苯 | −0.82 | −0.90 | 0.20 | 91.89 |
| 002 乙醇 | −5.42 | −5.00 | 0.60（默认赋值） | 72.00 |
| 003 乙醚 | −2.11 | −1.59 | 0.60（默认赋值） | 58.73 |
| 004 苯甲醚 | −1.98 | −2.45 | 0.60（默认赋值） | 63.31 |

能量/uncertainty 单位均为 kcal/mol。默认 0.60 不是对该分子直接测量得到的精确
置信区间，不能据此自动设 τ。原配置明确写 expert calculation checked against
FreeSolv，故中心不同本身不证明 gold 错误；问题是题面只问水相溶剂化自由能，未定义
要复现哪一个 expert 方法。如果 benchmark 声称评估真实性质，就应解释实验中心为何
只得 59–72 分；如果评估固定计算方法，就需公开该方法及标准态。

Basic 013 另有结构对应风险：题面两条 SMILES 含额外 N-甲基，RDKit 分子式分别为
C6H7N5、C6H8N2O2；常规未甲基化 adenine/thymine 是 C5H5N5、C5H6N2O2。不能仅凭
“S22 A–T”标签，把未甲基化复合物的参考值和不确定度直接移用到该题。
这不是本轮确定的 gold 错误，需原始几何和参考条目证实。

### 6. 精确小数显示出样本边界拟合，而非化学精度

- Basic 024：τ=0.03698216，GPT/off 的误差=0.0369815182，相差约 0.0017%。
- Basic 039：τ=1.3387056 cal/(mol·K)，GPT/off 的误差=1.34，刚好被截到零分。
- Basic 050：同一 RI-TDA-B3LYP/def2-SVP 激发能家族中 τ=0.18 eV，其余四题 τ=0.5 eV；
  当前未给出为何吡嗪需要约 2.8 倍严格要求的独立证据。

这些不证明偏袒某个模型，但说明当前数值主要响应特定作答。保留 6–8 位小数并不会
增强化学依据。科学校准后再保留合理有效数字，比直接发布拟合边界更容易解释。

## 怎样保留线性规则并提高发布可解释性

1. **先冻结所测量的量。** 明确实验预测、固定方法复现或代理描述符；公开决定结果的
   方法/状态/几何/分析定义不等于泄漏 gold。无法确定的题先核验原始数据。
2. **分开误差来源。** 记录 gold 测量/计算不确定度、舍入精度、协议复现误差、允许的
   近似方法误差。不能把输出小数位、方法 RMSE 或重复采样95%区间直接称为 τ。
3. **给分数锚点化学解释。** 为同性质家族先声明什么误差算高质量（例如 s*=0.9）、
   什么误差只算有限近似、什么误差无用，再把这些选择映射到现有线性宽度。
   同类题单独更严需要分子/状态/参考质量证据，不能只有当前答题分布。
4. **使用独立校准集。** 确定科学上允许的参数范围后，可以用独立开发集的答案区分度
   优化宽度并做有效数字圆整；随后冻结并在未用于定参的模型/运行上验证。
   本轮四组答案只能作为探索集，不能同时充当最终校准与独立验证。
5. **单列评分语义问题。** 能量符号、负距离、整数输入、百分比定义需独立处理，
   某些问题无法只通过数值容差修复。本次不扩大为运行时修改。
6. **发布证据包。** 每题给出 gold 来源、原始计算/测量的可审核记录、单位和归一化、
   左右 τ的推导、高分/零分锚点、独立复测结果以及适用范围。

因此，不建议立刻用另一组“看起来化学上常见”的数值替换当前 τ。可以保留不少数值
作为待检验候选，但**现有证据不足以将整批参数宣称为“经过化学验证的正式容差”**。
