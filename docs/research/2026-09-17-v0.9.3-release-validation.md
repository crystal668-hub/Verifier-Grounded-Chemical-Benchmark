  dependency and live-backend conditions. One existing CIF warning concerns
  missing formula keys.
- Ruff checks on changed Python files and `uv lock --check` passed.
- Tests compare every released scoring field with the frozen R2 configuration.
- Historical replay reproduced the R2 summary statistics, all 71 task rows and
  all 77 field rows exactly, using the v0.9.2 inventory as the original baseline.

  from outside the checkout. The imported module path and distribution version
